# Installation

## Requirements

- Node.js 20 or later
- npm
- HTTPS for deployed WebAuthn origins

## npm

```sh
npm install iskubixi
```

## CommonJS

```js
const { IskuBixi } = require("iskubixi");
```

## TypeScript

```ts
import { IskuBixi } from "iskubixi";
```

The package is published as CommonJS with TypeScript declarations. It does not
publish a separate native ESM entry.
